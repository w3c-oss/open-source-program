# WebMCP Polyfill Project

[WebMCP Polyfill](https://github.com/w3c-oss/webmcp-polyfill) is a polyfill for [WebMCP](https://webmachinelearning.github.io/webmcp/), with no runtime JavaScript dependencies.

This is a pilot of the W3C Open Source Program. Documentation related to the pilot includes:

* [Program requirements for the WebMCP Polyfill project](project-reqs.md)
