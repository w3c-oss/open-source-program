# Pilot preparation for the W3C Open Source Program

**Status**: This documentation is focused on the pilot phase of the W3C Open Source Program. We will continue to develop as we learn from pilots, and this will inform "getting involved" documentation for a future operational program.

We welcome discussions about becoming a pilot Project. 

If you would like your project to be considered as a pilot, please let us know via one of the [feedback mechanisms](https://github.com/w3c-oss/open-source-program#feedback).

Note: We may not be able to accept a large number of pilot Projects while in pilot mode.

## Scope

W3C seeks to build a coherent Web architecture. Projects hosted at W3C would mature within an ecosystem that seeks to build a coherent open platform through processes and IPR policies designed to support interoperability, quality, and [W3C values](https://www.w3.org/TR/w3c-vision/). 

Pilot Projects should help accelerate the adoption of Web standards or support the Web standards community (including through tooling and by helping ensure that standards remain relevant and connected to developer realities) and would benefit from streamlined feedback loops with standardization activities.

## What we'll need to set up the Project

The W3C staff managing the pilots will work with you on these topics to understand how we can best serve your Project:

* A Statement of Purpose of the Project
* Governance
  * Who are the initial Code Owners for this Project?
  * Are there governance details to document? For example, we anticipate that many Projects will delegate code integration decisions to Code Owners, but that this will be done with input from a Support Committee such as a W3C group.
  * Are there aspects of governance where W3C can provide particular value to your Project?
* Licensing
  * What are the licensing preferences of the Project? (By default we are using an "Apache 2 system.")
  * We also will ask contributors to agree to a [W3C Open Source Individual Contributor License Agreement](https://www.w3.org/2026/07/w3c-open-source-icla.html) and we will want to show you our tooling for how we will collect those agreements.
* Roadmap
  * What does the Project hope to accomplish in the next year? 
  * What are the resource needs (cost, hosting, etc.) for the work? 
  * Are there potential Supporters for the work who may provide funding, hosting, or other resources to support the Roadmap?
* Assets
  * Does the Project have any assets that will be transferred to W3C (e.g., domain names, logos, trademarks)?

## Repo setup

* In pilot mode we prefer that Projects set up a repo in the w3c-oss organization.
* We will set up the [cla-checker](https://github.com/w3c-oss/cla-checker) to collect contributor agreements.
* We have started work on [templates](https://github.com/w3c-oss/open-source-program/tree/main/templates). More work is necessary as well as tooling to help automate repo setup.
