# W3C Open Source Program Community Group Charter

In September 2026 W3C [announced](https://www.w3.org/blog/2026/w3c-launches-first-pilot-of-program-to-support-open-source-projects/) a first pilot project for a new Open Source Program. The mission of this Community Group is to manage the next phase of growth of the W3C Open Source Program, especially regarding overall program governance.

# Goal

The group has a goal for W3C to launch a full Open Source Program by mid-2028. It is assumed that once the full program has launched, this Community Group will be archived.

# Scope and deliverables

This Community Group will study what is needed to create a scalable W3C Open Source Program. The group expects to study and make recommendations regarding topics such as the following.

Projects:

* Scope
* Lifecycle framework (including mechanisms for saving information to satisfy regulatory requirements). 

Governance:

* Policies governing all projects (e.g., Code of Conduct) and whether any changes to existing W3C policies would be appropriate or necessary for the realm of open source.
* Decisions regarding lifecycle status changes
* Whether and how to handle escalation of disputes within a Project
* The relationship of the program to W3C Membership (if any)
* Interactions between governance and donations
* The constitution of a program committee
* Requirements for a project to establish a security posture and guidelines for doing so.
* Licensing / IPR

Running an open source program:

* Regulatory matters (e.g., restricted entities, cyber resilience steward role, etc.) and providing infrastructure for projects to demonstrate responsible stewardship (e.g., security attestations).
* Implications of running this program as a 501(c)(3)
* Providing infrastructure for responsible security reporting and making available vulnerability fixes
* Outreach to OS program offices in W3C Members
* Liaisons with Open Source organizations
* Outreach to open source developers, and facilitate connections to other standardization organizations where relevant.


## Out of Scope

This group does not play a role in determining which pilots are part of the Program. However, the W3C staff will keep the group informed of pilot progress to inform discussions.

# Liaisons

This group will liaise with the W3C Advisory Board as a way to facilitate information sharing in both directions about the W3C Open Source Program.

This group also expects to continue discussions with open source hosting organizations such as the Apache Foundation, Linux Foundation, OpenSSF, and Eclipse Foundation.

# Confidentiality and communication

The group will conduct its work in public, except where confidentiality is appropriate to protect sensitive information related to personnel matters and resource allocation. The community is invited to raise issues in the [Community Group’s public repo](https://github.com/w3c-oss/open-source-program).

People may also contact the Chair(s) and W3C Staff privately via group-oss-program@w3.org.

# Amendments to This Charter

The Community Group Chair(s) can amend this charter and should only do so with the consensus of the Community Group.
